# Git and pull requests

In every repository, read `~/.agents/skills/git-management/SKILL.md` before
committing, pushing, creating a PR, contributing code to a PR, or maintaining PRs.
Follow its review loop: keep PRs ready for review (never draft) so Codex reviews
every push automatically, check back within 30 minutes, and reply to each comment,
within the current request, repository protections, and release holds.
`pr-management` is a compatibility entrypoint to the same workflow.
