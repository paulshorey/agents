# Git and pull requests

In every repository, read `~/.agents/skills/git-management/SKILL.md` before
committing, pushing, creating a PR, contributing code to a PR, or maintaining PRs.
Follow its Codex review loop, 30-minute timeout, and per-comment replies within
the current request, repository protections, and release holds. `pr-management`
is a compatibility entrypoint to the same workflow.
